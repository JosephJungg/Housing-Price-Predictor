# Housing-Price-Predictor
A machine learning project that predicts housing sale prices using real estate data and regression models. Using Python, Pandas, NumPy, and Scikit-learn, the project involved data cleaning, exploratory data analysis, feature engineering, and model optimization to identify patterns in housing features associated with sale prices.

Implemented and evaluated regression models to predict log-transformed sale prices, improving model performance by reducing RMSE from 1.1 to 0.65 through iterative refinement and feature selection.
